# 게스트 로그인 추가

작성일: 2026-10-31

시작 화면에 **게스트로 시작하기**를 추가했다. Firebase 설정, 네트워크 연결,
Google·Apple 계정 없이 홈으로 들어가 기존 로컬 기능을 사용할 수 있다.

게스트 접근은 Firebase 인증과 별도인 메모리 세션이다. 가짜 Firebase UID를 만들거나
온라인 사용자로 등록하지 않는다. 앱을 완전히 종료·재실행하면 시작 화면에서 다시 선택한다.
기존 로컬 계좌·기록은 유지한다. 게스트에게 온라인 계정 ID나 랭킹 참여 기능을 제공하지 않는다.

내 계좌 → DreamBank 계정에서 게스트 상태 확인과 **게스트 이용 종료**가 가능하다.
종료하면 시작 화면으로 돌아가며 로컬 기록은 지우지 않는다. 같은 화면에서 Google·Apple
로그인을 시도할 수 있다. 실제 인증에 성공하면 게스트 상태를 해제하며, 이후 계정 로그아웃 시
게스트 상태가 남아서 자동 진입하지 않도록 했다. 실제 계정 로그인에는 기존 Firebase 설정이 필요하다.

검증: 전체 단위·위젯 테스트 48개 통과. 게스트 진입/종료, 로컬 계좌 보존,
실제 인증 상태로의 전환과 로그아웃 후 게스트 접근 해제를 확인했다.
정적 분석은 문제 없으며 iOS 시뮬레이터 빌드를 통과했다.

Android 에뮬레이터 통합 테스트에서도 게스트 홈 진입, 계정 화면의 게스트 상태,
이용 종료 후 시작 화면 복귀와 계좌 데이터 동일성을 확인했다.
검증 로그는 [guest-login-evidence](guest-login-evidence/)에 저장했다.
