# 시작 로그인 화면 적용 결과

작성일: 2026-10-31

후속 변경: 게스트 시작 경로가 추가되었다. 현재 동작은 [guest-login-report.md](guest-login-report.md)를 참고한다.

## 변경한 동작

앱을 열면 DreamBank 브랜드와 이미지, Google·Apple 로그인 버튼을 먼저 표시한다.
인증 상태 복원 중이나 미로그인·오류 상태에서는 홈·계좌·편지 등 앱 본문을 생성하지 않는다.
로그인된 세션이 확인되면 홈으로 이동하고, 로그아웃하면 로그인 화면으로 돌아간다.
시스템 뒤로가기나 내부 계좌 URL로 로그인 화면을 우회할 수 없다.

Firebase 설정이 없어도 로그인 버튼은 표시한다. 버튼을 누르면 실제 연결 준비 상태를 안내하며,
임시 사용자나 로그인 건너뛰기를 제공하지 않는다. 따라서 현 빌드는 아직 로그인 화면에서
진행할 수 없다. 실제 사용에는 [인증 설정 안내](auth-setup.md)의 외부 연결 작업이 필요하다.
이전 로컬 계좌 데이터는 삭제하거나 변경하지 않는다.

## 검증 결과

- 정적 분석: 문제 없음.
- 전체 단위·위젯 테스트: 46개 통과.
- 인증 전 본문 숨김, 내부 계좌 경로 차단, 인증 후 홈 이동, 로그아웃 후 재잠금 검증.
- Android 에뮬레이터 통합 테스트: 시작 로그인, 설정 준비 안내, 뒤로가기 우회 차단 통과.
- 최종 UI Android debug APK / iOS simulator debug 빌드 통과.
- Android 에뮬레이터에 일반 앱 업데이트·실행 완료. 첫 화면에서 두 로그인 버튼 표시 확인.
- 실제 OAuth 로그인은 Firebase·Google·Apple 설정 부재로 아직 검증하지 못함.

검증 로그와 실제 화면은 [auth-startup-evidence](auth-startup-evidence/)에 저장했다.
로컬 기능 회귀 테스트는 테스트 전용 인증 상태를 주입한다. 배포 앱에는 우회 경로가 없다.
